# MyZLM MC 配套网站

纯 Node.js（零依赖）实现，与 MC 服务器实时联动：

- 通过 **Server List Ping 协议** 直连探测服务器（在线状态、版本、MOTD、延迟、在线玩家）
- 深色游戏风仪表盘，15 秒自动刷新
- 一键复制服务器地址、加入指南

## 启动

双击 `启动网站.bat`，浏览器打开 http://localhost:3000

## 配置（启动网站.bat 内环境变量）

| 变量 | 说明 | 默认 |
|---|---|---|
| `WEB_PORT` | 网站端口 | 3000 |
| `MC_HOST` | MC 服务器地址 | 127.0.0.1 |
| `MC_PORT` | MC 服务器端口 | 25565 |
| `PUBLIC_IP` | 页面展示的对外 IP/域名 | 留空显示内网地址 |

局域网好友访问：`http://你的内网IP:3000`（首次启动 Windows 防火墙需放行 node/3000 端口）。
